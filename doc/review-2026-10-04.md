# Targeted functional review — 2026-10-04

## Scope

Acquisition loop, recording/resume, sample metadata, incremental statistics, CSV serialization and interval control behavior.

## Finding and fix

### Resumed-run sample timestamps

Sample start times used sampleCount times the current interval. Recording two 2-second samples, stopping, switching to a 1-second interval and resuming stamped the next sample at 2 seconds, overlapping an existing sample. Start times now follow the previous sample end, including samples appended within the current frame. A regression expects [0, 2, 4] for this sequence.

## Validation

- `npm run lint`, `npm run check`, `npm test` (125 passing tests), and `npm run build` passed.
- `npm run test:fuzz:quick` passed: pointer and keyboard smoke, 10 seconds each.
- The new regression failed with the original behavior and passed with the fix.
- Checks used the available Node 22.12.0 runtime; the repository declares Node >=24.
